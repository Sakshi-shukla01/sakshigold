# Sakshi Gold - Virtual Jewelry Try-On

A web-based virtual jewelry shopping platform with **try-on features**, live gold pricing (GoldAPI), and cart/checkout functionality.

---

## **Project Features**

- Categories: Earrings, Rings, Bangles, Necklaces, Artificial Earrings, Anklets
- **Virtual Try-On** for: Earrings, Rings, Bangles, Necklaces
- Gold pricing based on **real-time gold rates** using GoldAPay
- Add to cart / Remove from cart / Checkout using pop-up
- User authentication: Register and Login

> ⚠️ Note: Try-On feature is not available for Artificial Earrings and Anklets.

---

## **Tech Stack**

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Other Libraries:** MediaPipe Face Mesh (for try-on feature), Canvas API
